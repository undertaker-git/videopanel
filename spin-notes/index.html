FIELD NOTE

为什么轨迹会收拢？

dm/dt = −γ m×B + α m×(dm/dt)

磁矩一边绕有效场进动，一边在阻尼作用下耗散能量。增大 α，进动圈数通常减少，磁化更快贴近平衡方向。γ/2π ≈ 28 GHz/T。

观察提示：逐渐增大阻尼，看看橙色轨迹的螺旋半径如何变化；时间曲线中的振荡包络也会随之改变。

01 / VECTOR BASICS

磁化是向量，不只是一个数

铁磁体的磁化强度 M 描述单位体积的磁矩。宏自旋近似把整个样品看成一个均匀向量。归一化后 m=M/Mₛ，理想情况下 |m|=1，因此运动发生在单位球面上。

τ ∝ M × B　　m = M/Mₛ

外磁场对磁矩施加力矩，力矩方向由叉乘决定。m 与 B 垂直时力矩最大；平行时力矩为零。

观察任务 改变初始偏角。偏角接近 0° 时，运动轨迹为什么变短？
02 / LLG DYNAMICS

进动与耗散同时发生

dm/dt = −γ/(1+α²)[m×Bₑff + αm×(m×Bₑff)]

第一项引起绕有效场进动；第二项表示 Gilbert 阻尼带来的耗散。有效场可包含外场、各向异性场、交换场和退磁场。能量逐步降低时，磁化趋向稳定方向。

这里 B 用 T，γ≈1.759×10¹¹ rad·s⁻¹·T⁻¹，α 无量纲。教材的符号约定可能不同，比较公式前先核对 γ、γ₀ 以及使用 B 还是 H。

03 / TWO FORMS

Gilbert 隐式式与显式式

Gilbert： dm/dt = −γm×B + αm×(dm/dt)

导数同时出现在等式两边，称为隐式 Gilbert 写法。代数整理后，可以将 dm/dt 单独解出：

显式： dm/dt = −γ/(1+α²)[m×B + αm×(m×B)]

显式形式便于直接数值积分。小 α 时 1+α²≈1；阻尼较大时忽略该因子会造成偏差。

自检：α=0 时阻尼项消失，磁矩仍会进动，却不会自行停在场方向。
04 / EXCHANGE LENGTH

网格需要多细？

lₑₓ = √(2Aₑₓ / μ₀Mₛ²)

交换长度估算交换能与退磁能竞争的典型尺度。Aₑₓ 为交换刚度，Mₛ 为饱和磁化强度。空间微磁模拟通常让单元边长不超过数个交换长度；畴壁、涡旋核心可能需要更精细网格，并比较不同网格的结果做收敛检查。

本页单宏自旋模型没有空间网格，因此看不到畴壁或涡旋结构。
05 / FERROMAGNETIC RESONANCE

FMR：外场和退磁共同决定频率

对面内饱和薄膜，简单 Kittel 关系为：

f = (γ/2π)√[(Bₑₓₜ+Bₖ)(Bₑₓₜ+Bₖ+μ₀Mₛ)]

Bₖ 是面内各向异性场。垂直饱和的理想薄膜近似 f=(γ/2π)(Bₑₓₜ−μ₀Mₛ)。形状、退磁张量、边界和交换模态会改变实际结果。

检查顺序：外场方向 → 样品形状 → 材料参数 → 单位约定 → 空间模态。

06 / PULSE & FOURIER

短脉冲激发，长时间窗读频率

横向高斯脉冲把磁化从平衡方向推开，随后产生自由进动。记录磁化分量，再对时域信号做傅里叶变换，可以观察共振峰。

Δf ≈ 1/tₘₐₓ　　fₙᵧq = 1/(2Δt)

延长总时长可提高频率分辨率；缩短采样间隔可提高 Nyquist 上限。零填充只让谱线插值更平滑，不会增加真实分辨率。

建议先调阻尼观察时域衰减，再改变外场比较进动快慢。

COMMON QUESTIONS

常见问题

为什么阻尼为零时磁化不会趋向外场？

进动项只改变磁化方向，不改变磁化与场的夹角，也不耗散能量。需要阻尼或其他耗散机制，系统才会弛豫到稳定态。

为什么空间模拟频率与宏自旋估算不同？

真实样品会出现非均匀模式，退磁场也依赖形状和边界。还需检查材料参数、外场方向、网格收敛和 FFT 时间窗。

这页可以代替 MuMax3 吗？

不能。这里用单个向量帮助理解方向和趋势；MuMax3 在空间网格上计算磁化分布，可模拟交换、退磁、畴壁和涡旋等结构。
